# Reproducing paper 3

Every number comes from `evaluation/results/*.json`, regenerated by:

```bash
python evaluation/evaluate_e2.py --n 40 --corpus v1            --json evaluation/results/v1.json
python evaluation/evaluate_e2.py --n 40 --corpus v1 --extended --json evaluation/results/v1_ext.json
python evaluation/evaluate_e2.py --n 40 --corpus v2            --json evaluation/results/v2.json
python evaluation/evaluate_e2.py --n 40 --corpus v2 --extended --json evaluation/results/v2_ext.json
python evaluation/pq_bench.py --iters 1000 --json evaluation/results/e3.json
```

The hash-salt finding in Section III (AUC 0.894 vs 0.922, FPR 6.9% vs 2.1%) was
measured on the evaluation script *before* the split was made stable: run the
pre-fix `evaluate_e2.py` (commit 8d25e3f) with `PYTHONHASHSEED=1` and `=2`.
